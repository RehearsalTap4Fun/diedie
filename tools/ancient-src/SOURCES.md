# 古文字素材出处

叠汉字「演变」动画中间一环（图画 → 甲骨文 → 今天的字）。全部来自 Wikimedia Commons
「Ancient Chinese characters」项目（按繁体字命名），公有领域。原文件放在本目录，
`node tools/prep-ancient.mjs` 去元数据、统一着色后输出到 `src/assets/ancient/c-*.svg`。
「手」没有甲骨文，用金文。
